# 🚀 Meus Estudos de HTML5

Este repositório foi criado para armazenar os meus códigos de prática e exercícios desenvolvidos durante o meu aprendizado de Desenvolvimento Web. Aqui estão guardados os meus primeiros passos estruturando páginas antes de começar a aplicar estilos.

## 📁 Práticas Inclusas

### 1. GamerFix (`gamerfix.html`)
Uma página de pouso (Landing Page) para um serviço de manutenção de videogames.
* **O que pratiquei:**
  * Estrutura básica do HTML5 e tags semânticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
  * Menu de navegação interna usando links âncora (`#id`).
  * Criação de formulário de orçamento com múltiplos tipos de inputs, placeholders e validação nativa de e-mail.

### 2. Portfólio Pessoal (`aprendizado1.html`)
A estrutura inicial de um portfólio profissional para apresentação de projetos.
* **O que pratiquei:**
  * Uso de comentários (`<!-- -->`) para organizar e documentar o código.
  * Tag semântica `<article>` para isolar conteúdos independentes (os cartões de projetos).
  * Organização de hierarquia de títulos avançada (`<h1>`, `<h2>` e `<h3>`).
  * Links com caminhos relativos para navegação entre páginas locais.

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Marcação Estrutural Semântica)
